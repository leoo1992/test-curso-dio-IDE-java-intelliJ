# Primeiro projeto Java — IntelliJ IDEA

Projeto inicial de estudo utilizado para praticar a criação e execução de uma aplicação Java na IDE IntelliJ IDEA, como parte de exercícios de curso da DIO.

## Stack
- Java
- IntelliJ IDEA

## Como executar
Abra o projeto no IntelliJ IDEA, configure um JDK compatível e execute a classe principal disponível em `src` pela própria IDE.
